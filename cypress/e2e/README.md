# Estructura de pruebas E2E

```
cypress/e2e/
├── auth/           # Autenticación (login, registro, etc.)
│   └── login.cy.js
├── cart/           # Carrito de compras (pendiente)
├── checkout/       # Proceso de pago (pendiente)
├── products/       # Catálogo y productos (pendiente)
├── E2E_SCENARIOS.md   # Catálogo de escenarios y estado de pruebas
└── README.md       # Este archivo
```

Ver **[E2E_SCENARIOS.md](./E2E_SCENARIOS.md)** para el listado completo de escenarios, prioridades y estado de implementación.
